# Tabfold

**탭은 가볍게. 생각은 여유롭게.**

복잡한 Chrome 창을 깔끔하게 접을 수 있는 탭 그룹으로 정리합니다. **변경 전에 먼저 확인하세요.**

**미리보기 → 검토 → 적용**

## Tabfold를 쓰는 이유

- **미리보기부터** — 탭을 변경하기 전에 제안된 그룹을 확인합니다.
- **AI 없이도 동작** — API 키 없이 제목·URL 단어의 TF-IDF와 코사인 유사도로 로컬 군집화합니다.
- **필요할 때만 AI** — OpenRouter 또는 TypeSafe를 통해 Jev로 더 세밀하게 분류합니다.
- **작업 맥락 유지** — 탭은 원래 창에 남고, 그룹만 접어 화면을 정돈합니다.
- **기본으로 보호** — 고정 탭, 소리 재생 중인 탭, 시크릿 탭, 내부 페이지, 기존 그룹의 탭을 보호합니다.
- **간편한 복구** — 마지막 그룹 정리를 되돌리고 중복 정리로 제거한 URL을 복원합니다.

## 사용 방법

1. 로컬 군집화 또는 AI로 **미리보기**를 만듭니다.
2. 제안된 그룹을 **검토**합니다.
3. 원하는 결과라면 **적용**합니다.

이것으로 끝입니다. Tabfold는 창을 합치거나 페이지를 바꾸지 않고 탭을 그룹으로 묶어 접습니다.

AI 실행 전부터 기존 그룹을 확인할 수 있습니다. 보존 모드는 같은 창의 적합한 그룹에 탭을 추가하며 기존 구성원과 그룹 모양을 유지합니다. 다른 창의 이름 있는 카테고리는 별도의 새 그룹으로 재사용할 수 있지만 창 사이로 탭을 옮기지는 않습니다. 재분류는 이름 있는 그룹의 목적을 참고해 구성원을 다시 묶으며, 호스트명만 있는 그룹은 카테고리 틀로 사용하지 않습니다.

고정·재생 중·시크릿·내부 페이지는 계속 보호합니다. 제안된 그룹만 적용하고 새 그룹은 탭이 최소 2개 있어야 하며, 짝이 없는 단독 탭은 원래 위치에 남습니다. 되돌리기는 가능한 경우 원래 그룹을 복원하지만 정확한 탭 순서는 보장하지 않습니다.

빠른 미리보기는 가벼운 카테고리 목적 규칙(예: YouTube는 Media/SNS, 채용 공고는 JobRecruit)을 먼저 참고하고 나머지는 로컬 TF-IDF·코사인 유사도로 군집화합니다. 임베딩이나 사전 학습 신경망이 아닌 어휘 기반 방식으로, 모델 다운로드나 서버 요청이 없습니다. JavaScript 모듈은 Node.js에서도 동작합니다.

팝업은 재분류, 저장된 카테고리 무시, 새 카테고리 제안을 각각 저장합니다. 카테고리 무시는 저장된·기본 AI 선택지를 삭제하지 않고 제외하며, 기존 Chrome 그룹 이름은 재분류에서도 참고합니다. AI에는 그룹 이름, 포괄적 목적, 서로 다른 예시 탭 최대 6개의 제목·쿼리 없는 URL origin/path가 전송될 수 있습니다. 새 주제 후보는 기존 분류에 맞지 않는 탭에서만 추출하고 Jev로 검증합니다.

**기존 그룹 이름 사용**은 기본으로 켜져 있으며, **저장된 카테고리 무시**와 별개로 이 옵션을 끄고 재분류하면 기존 그룹 맥락 없이 다시 시작합니다. 끄면 기존 그룹 메타데이터·예시는 전송하지 않지만 분류 대상 탭 제목·URL은 여전히 AI로 보냅니다.

## 설치

1. 이 저장소를 다운로드하거나 복제합니다.
2. `chrome://extensions`를 엽니다.
3. **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 클릭하고 `extension` 폴더를 선택합니다.
5. 도구 모음에 **Tabfold**를 고정합니다.

빌드나 패키지 설치가 필요하지 않습니다.

## 나에게 맞게 설정

**설정**에서 다음을 변경할 수 있습니다.

- 최대 **12개의 사용자 지정 카테고리** 만들기
- 탭 정렬을 **현재 순서 / 제목 / 오랫동안 사용하지 않은 순서** 중 선택
- 새 주제 제안을 검토한 뒤 추가
- JSON으로 카테고리 가져오기·내보내기
- 영어, 프랑스어, 한국어, 중국어 간체·번체, 러시아어, 일본어, 튀르키예어, 스페인어로 언어 변경

‘기타’ 분류는 자동으로 처리합니다.

## AI는 선택 사항

로컬 미리보기는 브라우저 안에서만 처리됩니다.

AI 미리보기를 사용하려면 **설정 → AI 연결**에서 **OpenRouter** 또는 **TypeSafe**를 선택하고 해당 제공자의 API 키를 입력하세요.

- OpenRouter는 **Decisions API**를 사용합니다.
- TypeSafe는 **Jev 1.13**을 사용합니다.
- API 키는 Chrome **세션 저장소**에 보관하며 브라우저를 종료하면 삭제됩니다.
- **다른 제공자로 자동 전환하지 않습니다.**

## 개인정보 보호

| | |
|---|---|
| **로컬 미리보기** | 외부 전송 없음 |
| **AI 미리보기** | 탭 제목, URL 출처·경로, 카테고리 기준 전송 |
| **전송하지 않는 정보** | 페이지 본문, URL 인증 정보, 쿼리 문자열, 프래그먼트 |
| **API 키** | 세션에만 저장 |
| **분석·광고** | 없음 |

제목과 URL 경로에도 민감한 정보가 포함될 수 있습니다. 자세한 내용은 [개인정보 보호](../docs/PRIVACY.md)를 참고하세요.

### 명시적 분류 선호

Google 검색 결과(`google.com` / `google.co.kr`의 `/search`)는 **Google search**, Toss Invest는 **Investment**로 우선 분류합니다. 빠른 미리보기와 AI 미리보기 모두 적용하며 기존 그룹 이름·저장된 AI 카테고리 무시와 별개입니다. Google 문서·메일이나 회사 이름만 언급한 페이지까지 포함하지 않습니다. 같은 창의 기존 그룹을 재사용하되, 같은 이름이 여러 개면 세 번째 그룹을 만들지 않고 보류합니다.
