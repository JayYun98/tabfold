Jev помогает группировать вкладки по контексту. Проверьте результат и примените: каждое окно упорядочивается отдельно, без объединения окон.

*Озвучка на английском · Иллюстративная демонстрация, а не запись реального экрана.*

## Зачем нужен Tabfold

- **Сначала просмотр** — посмотрите на предложенные группы, прежде чем Tabfold изменит вкладки.
- **Работает без ИИ** — осторожно группирует заголовки с помощью TF-IDF и косинусного сходства, без ключа API.
- **ИИ по желанию** — используйте Jev через OpenRouter или TypeSafe для более точной классификации.
- **Сохраняет контекст** — вкладки остаются в исходных окнах; группы просто сворачиваются, освобождая место.
- **Защита по умолчанию** — закреплённые, звучащие, приватные, внутренние и уже сгруппированные вкладки защищены.
- **Простое восстановление** — отмените последнюю группировку и восстановите URL, удалённые при очистке дубликатов.

## Как это работает

1. **Создайте предварительный просмотр** с локальной кластеризацией или ИИ.
2. **Проверьте** предложенные группы.
3. **Примените**, если результат вас устраивает.

Вот и всё. Tabfold группирует и сворачивает вкладки, не объединяя окна и не заменяя страницы.

Группы видны до запуска ИИ. Режим сохранения добавляет подходящие вкладки в группы того же окна, не меняя прежних участников и оформление. Именованные категории из других окон могут стать отдельными локальными группами; вкладки не перемещаются между окнами. Перегруппировка меняет состав, сохраняя назначение именованных групп; названия, состоящие только из имени хоста, не служат шаблонами.

Закреплённые, воспроизводящие звук, внутренние вкладки и вкладки инкогнито защищены. Применяются только предложенные группы; новым нужны минимум две вкладки, одиночные остаются на месте. Отмена по возможности восстанавливает исходные группы, но не гарантирует точный порядок вкладок.

Быстрый просмотр осторожно группирует заголовки с помощью TF-IDF, косинусного сходства и метода полной связи (complete-link). Эмбеддинги и предобученные нейросети не используются; загрузка моделей и серверные запросы не нужны. Единственное фиксированное правило относит файлы изображений к **Images** по расширению. Жёстких категорий для сайтов или тем нет.

Перегруппировка, исключение сохранённых категорий, использование существующих названий и предложения настраиваются отдельно. При неуверенном решении ИИ вкладка остаётся без категории: лексическая кластеризация не подменяет решение. При использовании существующих названий могут передаваться названия, описания, примеры заголовков и URL без параметров запроса. Новые группы предлагаются экспериментально: точность не гарантируется, проверяйте их перед принятием или применением.

**Использовать названия существующих групп** включено по умолчанию: отключите этот параметр при включённой перегруппировке, чтобы начать без прежнего контекста, независимо от **Игнорировать сохранённые категории**; метаданные и примеры существующих групп тогда не передаются, но заголовки и URL доступных для классификации вкладок по-прежнему отправляются ИИ.

## Установка

1. Скачайте или клонируйте этот репозиторий.
2. Откройте `chrome://extensions`.
3. Включите **Режим разработчика**.
4. Нажмите **Загрузить распакованное расширение** и выберите папку `extension`.
5. Закрепите **Tabfold** на панели инструментов.

Сборка и установка пакетов не требуются.

## Настройте под себя

В **Настройках** можно:

- Создать до **12 собственных категорий**
- Выбрать порядок вкладок: **текущий / по заголовку / давно не используемые первыми**
- Проверить предложенные новые темы перед добавлением
- Импортировать и экспортировать категории в формате JSON
- Выбрать английский, французский, корейский, упрощённый китайский, традиционный китайский, русский, японский, турецкий или испанский язык

Категория «Другое» учитывается автоматически.

## ИИ необязателен

Локальный предварительный просмотр полностью выполняется в браузере.

Для просмотра с ИИ выберите **OpenRouter** или **TypeSafe** в **Настройки → Подключение ИИ** и добавьте ключ API выбранного провайдера.

При включённых **предложениях новых групп** OpenRouter создаёт названия и критерии с помощью GPT-4.1, а Jev классифицирует вкладки. Новые группы относятся только к текущему предварительному просмотру и не меняют сохранённые категории. Возможны дополнительные вызовы и расходы. Прямое подключение TypeSafe использует только Jev и не переключается автоматически на OpenRouter.

- OpenRouter использует Jev для классификации и GPT-4.1 для новых названий групп. Возможны дополнительные вызовы API.
- TypeSafe использует **Jev 1.13**
- Ключи API сохраняются в **хранилище сеанса** Chrome и удаляются при закрытии браузера
- **Автоматического переключения на другого провайдера нет**

## Конфиденциальность

| | |
|---|---|
| **Локальный просмотр** | Данные не отправляются наружу |
| **Просмотр с ИИ** | Отправляются заголовки вкладок, источники и пути URL, критерии категорий |
| **Никогда не отправляются** | Содержимое страниц, учётные данные в URL, строки запроса, фрагменты |
| **Ключи API** | Хранятся только в течение сеанса |
| **Аналитика / реклама** | Отсутствуют |

Заголовки и пути URL всё же могут содержать конфиденциальную информацию. Подробнее — в [политике конфиденциальности](../docs/PRIVACY.md).
