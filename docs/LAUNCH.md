# Tabfold 출시 자료

## 한 줄 소개

탭을 접고, 생각을 펼치세요. 미리 보고 정리하는 Chrome 탭 매니저.

## 짧은 설명

흩어진 탭을 주제별로 묶고 접으세요. 로컬 정리와 선택형 Jev 1.13 AI, 중복 확인, 그룹 되돌리기를 제공합니다.

## 제품 소개

찾던 문서보다 열린 탭이 먼저 눈에 들어오나요?

Tabfold는 브라우저에 작은 여백을 만듭니다. 정리안을 확인하고, 관련 탭을 그룹으로 묶고, 잠시 접어두세요. 고정 탭과 기존 그룹은 그대로 유지합니다.

기본 정리는 계정이나 API 키 없이 동작합니다. 조금 더 맥락 있는 분류가 필요할 때는 OpenRouter의 Jev 1.13을 연결하세요. AI는 요청할 때만 실행됩니다.

현재 비공개 프리뷰입니다. 확장 폴더를 로드해 사용할 수 있으며 Chrome 웹 스토어에는 아직 출시하지 않았습니다.

## 출시 게시글 초안

탭을 닫으면 맥락을 잃고, 열어두면 길을 잃는 사람을 위해 Tabfold를 만들었습니다.

정리안 미리보기 → 주제별 그룹화 → 그룹 접기.
로컬 규칙으로 바로 사용하고, 원할 때 Jev 1.13으로 분류합니다.

고정 탭·기존 그룹을 보호하고, 중복 탭은 따로 확인한 뒤 정리합니다.
지금은 비공개 프리뷰를 다듬는 중입니다.

## 메시지 원칙

- 정확도·메모리 절감·시간 절약 수치는 측정 전 주장하지 않습니다.
- AI 모드를 ‘100% 로컬’이라고 소개하지 않습니다.
- 그룹 접기와 탭 닫기를 구분합니다.
- 로컬 기능은 무료이며 OpenRouter AI 사용료는 별도입니다.
