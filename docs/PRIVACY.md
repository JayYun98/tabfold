# 개인정보 안내

Tabfold는 자체 서버, 계정, 분석 도구, 광고 추적을 사용하지 않습니다.

로컬 정리는 활성화된 기존 그룹의 예시 제목과 대상 탭 제목의 TF-IDF 가중치·코사인 유사도를 Chrome 안에서 계산합니다. 이미지 파일 확장자 외에는 사이트별 고정 분류 규칙을 사용하지 않습니다. 사전 학습 모델을 다운로드하거나 서버로 요청하지 않으며, 언어 간 의미 번역이 아닌 어휘의 유사성을 비교합니다. AI 버튼을 누르면 대상 탭의 제목(최대 240자)과 URL origin/path를 선택한 제공자로 보냅니다. TypeSafe 선택 시 TypeSafe API에 직접 연결하며, OpenRouter 선택 시 OpenRouter를 통해 TypeSafe Jev 1.13에 보냅니다. 새 그룹 제안을 켜면 OpenRouter를 통해 OpenAI GPT-4.1에도 정제된 제목·주소와 카테고리 정보를 보내 그룹 이름을 만듭니다. TypeSafe 키를 OpenRouter로 보내거나 공급자를 자동 전환하지 않습니다. URL의 쿼리, 해시, 사용자명, 비밀번호는 제외합니다. 페이지 본문·쿠키를 읽지 않습니다. 제목과 경로에도 민감 정보가 포함될 수 있습니다.

OpenRouter 키와 TypeSafe 키는 별도로 보관하며 자동 대체하지 않습니다. API 키는 Chrome `storage.session`에만 저장됩니다. 키 지우기 버튼, 브라우저 종료, 확장 비활성화 또는 제거로 지워집니다. 디스크에 키를 직접 저장하거나 동기화하지 않습니다.

기본으로 켜진 기존 그룹 이름 사용 옵션에 따라 보존·재분류 모드 모두 이름 있는 기존 Chrome 그룹의 목적을 참고합니다. AI에는 그룹 이름, 선택적 포괄 목적, 그룹별 서로 다른 예시 탭 최대 6개의 제목·URL origin/path를 전송할 수 있으며 다른 창의 그룹도 포함될 수 있습니다. 호스트명만 있는 그룹은 카테고리 틀로 사용하지 않습니다. 예시 URL에서도 쿼리, 해시, 사용자명, 비밀번호는 제외하며 페이지 본문은 읽지 않습니다.

재분류에서는 정리 가능한 기존 그룹 탭도 분류 대상이므로 해당 탭의 제목·URL origin/path를 전송합니다. 고정·재생 중·시크릿·내부 페이지는 계속 제외합니다. 다른 창의 카테고리를 참고하더라도 탭을 창 사이로 이동하지 않습니다.

사용자 카테고리 이름과 기준은 기기에 저장하고 AI 실행 시 분류 기준으로 전송합니다. 저장된 카테고리 무시를 켜면 저장된·기본 AI 카테고리를 제외하지만 저장 목록을 삭제하지 않으며 기존 Chrome 그룹 맥락도 제외하지 않습니다. 새 주제 제안을 켜면 기존 분류에 맞지 않는 탭의 제목·주소와 로컬에서 추출한 후보를 추가 요청으로 보내 Jev로 검증합니다.

기존 그룹 이름 사용을 끄면 기존 그룹 메타데이터·예시는 전송하지 않지만 분류 대상 탭 제목·URL은 여전히 AI로 보냅니다. 이 설정은 저장된 카테고리 무시와 별개이며, 재분류와 함께 사용하면 기존 그룹 맥락 없이 다시 분류합니다.

정리 미리보기와 그룹 되돌리기 정보는 세션에 저장합니다. 중복으로 닫은 URL은 복원을 위해 기기의 `storage.local`에 보관하고 성공적으로 복원한 항목은 제거합니다. 확장을 제거하면 확장 저장소도 삭제됩니다. 중복 복원은 마지막 정리만 대상으로 합니다.

AI 사용에는 [OpenRouter 개인정보 정책](https://openrouter.ai/privacy)과 제공자의 정책이 적용됩니다. Tabfold는 외부 제공자의 보관 기간이나 사용 정책을 보증하지 않습니다.
