# 개인정보 안내

Tabfold는 자체 서버, 계정, 분석 도구, 광고 추적을 사용하지 않습니다.

로컬 정리는 제목·URL 단어의 TF-IDF 가중치와 코사인 유사도를 Chrome 안에서 계산합니다. 사전 학습 모델을 다운로드하거나 서버로 요청하지 않으며, 언어 간 의미 번역이 아닌 어휘의 유사성을 비교합니다. AI 버튼을 누르면 대상 탭의 제목(최대 240자)과 URL origin/path를 선택한 제공자로 보냅니다. TypeSafe 선택 시 TypeSafe API에 직접 연결하며, OpenRouter 선택 시 OpenRouter를 통해 TypeSafe Jev 1.13에 보냅니다. URL의 쿼리, 해시, 사용자명, 비밀번호는 제외합니다. 페이지 본문·쿠키를 읽지 않습니다. 제목과 경로에도 민감 정보가 포함될 수 있습니다.

OpenRouter 키와 TypeSafe 키는 별도로 보관하며 자동 대체하지 않습니다. API 키는 Chrome `storage.session`에만 저장됩니다. 키 지우기 버튼, 브라우저 종료, 확장 비활성화 또는 제거로 지워집니다. 디스크에 키를 직접 저장하거나 동기화하지 않습니다.

기본 보존 모드에서는 기존 그룹을 우선 분류하기 위해 같은 창의 그룹 이름과 예시 탭 제목·URL origin/path도 선택한 AI 제공자로 전송합니다. 예시 URL에서도 쿼리, 해시, 사용자명, 비밀번호는 제외하며 페이지 본문은 읽지 않습니다.

전체 재분류 모드에서는 기존 그룹 이름·맥락을 AI에 제공하지 않습니다. 정리 가능한 기존 그룹 탭도 분류 대상으로 포함되므로 그 탭들의 제목·URL origin/path는 전송합니다. 고정·재생 중·시크릿·내부 페이지는 계속 제외합니다.

사용자 카테고리 이름과 기준은 기기에 저장하고 AI 실행 시 분류 기준으로 전송합니다. 저장된 카테고리 무시를 켜면 저장된·기본 카테고리를 전송하지 않지만 저장 목록은 삭제하지 않습니다. 기존 Chrome 그룹 맥락 전송은 재분류 설정에 따라 별도로 결정됩니다. 새 주제 제안을 켜면 기타로 분류된 탭의 같은 제목·주소 데이터와 추출한 후보를 추가 요청으로 보냅니다.

정리 미리보기와 그룹 되돌리기 정보는 세션에 저장합니다. 중복으로 닫은 URL은 복원을 위해 기기의 `storage.local`에 보관하고 성공적으로 복원한 항목은 제거합니다. 확장을 제거하면 확장 저장소도 삭제됩니다. 중복 복원은 마지막 정리만 대상으로 합니다.

AI 사용에는 [OpenRouter 개인정보 정책](https://openrouter.ai/privacy)과 제공자의 정책이 적용됩니다. Tabfold는 외부 제공자의 보관 기간이나 사용 정책을 보증하지 않습니다.
